# SOP - Design System

Versión: 0.1

---

# Filosofía

El SOP no es una aplicación de productividad.

El SOP es un santuario personal.

Cada pantalla debe transmitir calma, claridad y propósito.

El usuario nunca debe sentirse abrumado.

Si un elemento no ayuda a tomar una decisión o recordar quién quiere ser, no debe existir.

---

# Principios

- Menos es más.
- Mucho espacio en blanco.
- Tipografía protagonista.
- Animaciones discretas.
- Colores neutros.
- Nada debe competir por la atención.

Negro profundo.

Blanco.

Gris.

---

# Tipografía

Título principal

Grande.

Negrita.

Mucho espacio alrededor.

Subtítulo

Pequeño.

Discreto.

Texto

Muy legible.

Nunca saturar la pantalla con texto.

---

# Espaciado

Cada sección debe respirar.

Siempre priorizar aire antes que más contenido.

---

# Componentes

Los componentes deben ser simples.

Cada componente debe tener una sola responsabilidad.

---

# Dashboard

Orden de lectura

1. Saludo

2. Fecha

3. Reflexión del día

4. Actividades

5. Objetivo

6. Progreso

---

# Regla principal

Antes de agregar una nueva función preguntarse:

¿Hace que el SOP sea más útil?

Si la respuesta es no, esa función no entra al proyecto.
