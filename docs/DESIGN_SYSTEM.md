# SER Design Language (SDL)

## Principles

### 1. Calm over productivity

The interface should communicate calm before speed.

### 2. Less is more

Every element must justify its existence.

### 3. Content is the protagonist

The interface supports; it never competes with the content.

### 4. Consistency

The same action should look and feel the same throughout the application.

### 5. Space to breathe

Whitespace is part of the design.

### 6. Accessibility

Contrast, text size, and touch areas always take priority over aesthetics.

## Colors

Proyecto SER uses a reduced and semantic palette.

It will not be designed using raw colors, but through meanings.

| Token | Purpose |
|--------|-----------|
| Background | Main application background |
| Surface | Cards and containers |
| Surface Elevated | Floating elements |
| Primary | Main action |
| Secondary | Secondary actions |
| Text Primary | Main text |
| Text Secondary | Supporting text |
| Border | Separators and boundaries |
| Success | Confirmations |
| Warning | Warnings |
| Danger | Errors |
| Accent | Highlight important information |

Rule:

Never use colors directly if a semantic token equivalent exists.

## Typography

Typography should convey serenity, clarity, and hierarchy.

### Titles

- Few words.
- Light or medium weight.
- Plenty of whitespace around them.

### Main text

- Easy to read.
- Never too small.
- Maximum contrast over the background.

### Secondary text

- Lower contrast.
- Used for dates, descriptions, and context.

### Rule

If two elements compete for attention, the hierarchy is poorly defined.

# SOP - Design System

# Philosophy

SOP is not a productivity application.

SOP is a personal sanctuary.

Every screen should communicate calm, clarity, and purpose.

The user should never feel overwhelmed.

If an element does not help make a decision or remember who they want to be, it should not exist.

---

# Principles

- Less is more.
- Plenty of whitespace.
- Typography as the protagonist.
- Subtle animations.
- Neutral colors.
- Nothing should compete for attention.

# Main rule

Before adding a new feature, ask:

Does this make SOP more useful?

If the answer is no, that feature does not belong in the project.

## Cards

Cards represent units of information.

They should never feel heavy.

### They should convey

- Calm.
- Space.
- Order.
- Clarity.

### They should avoid

- Strong shadows.
- Thick borders.
- High contrast.
- Visual saturation.

### Rule

The content should always stand out more than the card.
