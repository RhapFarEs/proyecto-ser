# USER FLOW

Version: 1.0

---

# Philosophy

Proyecto SER should feel like a place you want to return to every day.

It should never feel like an endless list of tasks.

Each screen should answer only one question.

---

# Main flow

Open the application

↓

Today screen

↓

Choose an action

↓

Perform the action

↓

Return to Today

↓

Close the application

The Today screen is always the center.
