# PRODUCT PRINCIPLES

This document defines the non-negotiable product rules for Proyecto SER.

It is intended as an internal reference for the product team.

---

## Rule 1

Reduce anxiety.

If a feature increases stress, pressure, or guilt, it does not belong.

---

## Rule 2

Reflection is more important than tracking.

Metrics exist only when they help self-awareness.

---

## Rule 3

Never punish the user.

Missing a day should never create shame.

The app always invites.

It never pressures.

---

## Rule 4

Everything begins with Today.

The experience should always bring the user back to the present moment.

---

## Rule 5

The interface should disappear.

Content is always more important than UI.

---

## Rule 6

Small steps beat heroic efforts.

The product should encourage consistency rather than intensity.

---

## Rule 7

Every screen must answer one question.

Avoid screens with multiple competing purposes.

---

## Rule 8

Silence is a feature.

Whitespace, simplicity, and restraint are intentional.

---

## Rule 9

The user owns the experience.

The app guides.

It never controls.

---

## Rule 10

Complexity is the last resort.

Always choose the simplest solution capable of solving the problem.

---

## Decision Filter

Before implementing any feature, ask:

Does this reduce anxiety?

Does this increase clarity?

Does this help intentional living?

Would I still build this if no competitor existed?

If any answer is "No", reconsider the feature.
