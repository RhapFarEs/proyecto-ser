# Proyecto SER Roadmap

## M1 — Foundation ✅

Goal

Build the architectural and product foundations.

Completed:

- Product Vision
- Product Principles
- User Journey
- SDL
- Domain Model
- Today Experience
- Navigation
- Views
- Modules

---

## M2 — Journal Experience

Goal

Deliver the first complete journaling experience.

Includes:

- Welcome
- Mood
- Prompt
- Writing
- Closing
- Save Entry

---

## M3 — Habit System

Goal

Create a flexible habit engine.

Includes:

- Habit Entries
- Daily Completion
- Habit Modules
- Streak philosophy (without pressure)

---

## M4 — Purpose

Goal

Help users define direction.

Includes:

- Purpose statement
- Values
- Long-term vision
- Goals connected to purpose

---

## M5 — Insights

Goal

Help users discover patterns.

Includes:

- Weekly Review
- Monthly Reflection
- Entry Trends
- Emotional Patterns

---

## M6 — Personal Operating System v1

Goal

Integrate every module into one calm daily experience.

The application becomes a complete operating system for intentional living.

---

## Long-Term Vision

Proyecto SER should become the calmest and most intentional personal operating system ever built.

Every milestone should make the product simpler, more human and more meaningful.

Avoid dates.

Use milestones instead of sprints.
