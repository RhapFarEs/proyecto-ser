# Journal Experience Specification

## Goal

Help the user understand themselves through intentional writing.

Writing is the tool.

Self-awareness is the outcome.

---

## MVP

The first version includes:

- Welcome screen
- Mood selection
- Guided prompt
- Writing area
- Closing reflection
- Save entry

No AI.

No tags.

No search.

No editing history.

---

## User Flow

1. Open Journal
2. Select current mood
3. Read one reflection prompt
4. Write freely
5. Write one closing sentence
6. Save

---

## Screens

### Welcome

Purpose:
Reduce friction before writing.

---

### Mood

Purpose:
Help the user become aware of their emotional state.

---

### Prompt

Purpose:
Offer one meaningful question.

Only one.

---

### Writing

Purpose:
Provide a distraction-free writing experience.

---

### Closing

Purpose:
End intentionally.

---

## Design Principles

Minimal.

Calm.

No pressure.

No timers.

No word count.

No streaks.
